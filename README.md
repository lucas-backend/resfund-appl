# ResFund (mockup frontend)

React + TypeScript + Vite + react-router-dom. Semua data statis di `src/data.ts`.

    npm install
    npm run dev

Rute: `/` (UI-01), `/proyek/:id`, `/masuk` (UI-02), `/peneliti` (UI-03), `/peneliti/proposal` (UI-04),
`/peneliti/milestone` (UI-05), `/donasi/:id` (UI-06), `/donatur` (UI-07), `/reviewer` (UI-08),
`/admin` (UI-09), `/laporan/:id` (UI-10). Ganti peran lewat dropdown "Lihat sebagai" di header.
